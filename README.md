An interactive web-based mathematics learning application that helps users solve mathematical problems and understand the solution step by step.

The Virtual Maths Teacher is designed to make mathematics easier and more interactive for students and learners. Users can enter mathematical expressions or equations, select their preferred language, and receive answers along with step-by-step explanations.

🎮 How It Works
Enter a mathematical problem in the input box.
Select your preferred language.
Click the Answer button.
The application calculates the result.
Step-by-step explanations are displayed.
Click Play Steps to automatically highlight and explain each step.

You can also upload a .txt file containing a mathematical problem.

🎯 Project Objective

The main objective of this project is to create an interactive virtual mathematics learning assistant that not only provides answers but also helps users understand how the answer is obtained.

Instead of simply displaying the final result, the application provides step-by-step explanations, making it useful for students who want to learn mathematical concepts in a more interactive way.
